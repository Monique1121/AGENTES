Este repositorio contiene el proyecto de modelación de sistemas multiagentes con gráficas computacionales.

Nuestro proyecto busca atacar el problema de la movilidad urbana en México, sobre todo la congestión vehicular. La idea es construir un sistema multiagente, donde cada auto, semáforo o estacionamiento funciona como un agente que toma decisiones y se comunica con los demás. Luego mostramos el resultado con una simulación gráfica del tráfico, para ver cómo cambia el flujo de vehículos con nuestra solución.

Para reducir la congestión podemos seguir alguna de estas estrategias:

- Asignar estacionamientos: el sistema controla los lugares disponibles en una zona y le da uno a cada auto, para que nadie ande dando vueltas buscando dónde estacionarse.
- Compartir el vehículo: si más personas viajan en el mismo auto, hay menos coches en la calle.
- Elegir rutas menos congestionadas: no siempre la más corta, sino la que tiene menos tráfico. Así hay más movilidad, menos consumo de gasolina y menos contaminación.
- Coordinar los semáforos: los semáforos ajustan sus tiempos entre ellos, o los autos avisan cuándo van a llegar a un cruce para que el semáforo decida cuándo dar la luz verde y cuánto debe durar.

En resumen, queremos demostrar con la simulación que, si los agentes se coordinan de forma inteligente, el tráfico fluye mejor.
